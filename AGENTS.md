# Contribution rules

This repository contains an unofficial macOS hobby launcher and documentation.

- Never add downloaded games, runtimes, installers, account data, or raw logs.
- Do not disable operating-system security or modify the official game.
- Keep documentation plain, visible, and free of personal development paths.
- Preserve third-party notices. Do not claim publisher approval or legal clearance.
- Separate measured results, user reports, and checks that have not been run.
- Run the relevant tests and release privacy audit before committing.
- Local work only unless the user explicitly authorizes publication.
